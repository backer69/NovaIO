# SOP: UI Theme

## Color Palette (Teal & Slate)
*Derived from "Teal/Slate" modern business palette.*

### Primary (Teal)
- `primary-50`: `#f0fdfa`
- `primary-100`: `#ccfbf1`
- `primary-500`: `#14b8a6` (Main Action)
- `primary-600`: `#0d9488` (Hover)
- `primary-900`: `#134e4a`

### Neutral (Slate)
- `slate-50`: `#f8fafc` (Background)
- `slate-100`: `#f1f5f9` (Card Bg)
- `slate-800`: `#1e293b` (Text Main)
- `slate-400`: `#94a3b8` (Text Muted)

## Components Rules
- **Buttons**: Rounded-md, px-4 py-2.
- **Cards**: White bg, shadow-sm, border border-slate-200, rounded-lg.
- **Inputs**: slate-100 bg, focus:ring-2 ring-primary-500.
